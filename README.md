# QoE prediction on the PoQeMoN dataset

CSC 7018 project: compare models that predict the MOS (1–5) of mobile video sessions from the
[PoQeMoN QoE dataset](https://github.com/Lamyne/Poqemon-QoE-Dataset).

## Contents

| Path | Description |
|---|---|
| `notebooks/poqemon-qoe-project.ipynb` | Full analysis: EDA, protocol, grid search, evaluation |
| `figures/` | Figures generated by the notebook (used in the report) |
| `results/` | `cv_summary.csv` (CV scores and best hyperparameters), `test_summary.csv` (held-out test scores) |
| `docs/project-guidelines.pdf` | Course guidelines |

## Data

No manual download is needed. On first run the notebook downloads `pokemon.csv` from
`https://raw.githubusercontent.com/Lamyne/Poqemon-QoE-Dataset/master/pokemon.csv` and caches it in `data/`
(git-ignored). To work offline, place the file at `data/pokemon.csv` manually.

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On macOS, XGBoost needs the OpenMP runtime: `brew install libomp`.

## Running the analysis

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/poqemon-qoe-project.ipynb
```

or open the notebook and use *Restart Kernel and Run All*. A full run takes about one minute on a laptop.

## Reproducibility

- Random seed: `SEED = 42` (split, CV folds, models, permutation importance), set in the first code cell
- Split: 80% / 20% of **users** (`StratifiedGroupKFold`, stratified on MOS, grouped by `user_id`)
- Tuning: `GridSearchCV` with 5-fold grouped CV on the training users, selected on macro-F1
- Grids and preprocessing: notebook Sections 4–5
- Package versions: `requirements.txt` (also printed by the notebook)
