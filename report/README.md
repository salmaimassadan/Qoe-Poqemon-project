# Report

LaTeX source of the project report. `main.pdf` is the compiled version. This folder is self-contained, so
it can be compiled on its own (for example on Overleaf).

| File | Content |
|---|---|
| `main.tex` | Report text |
| `references.bib` | Bibliography |
| `figures/` | Figures (generated by the notebook) |
| `tables/` | Result tables (generated by `make_tables.py`; do not edit by hand) |
| `make_tables.py` | Generates `tables/*.tex` from `../results/*.csv` |

## Overleaf

Zip this folder (`report/`) and upload it as a new project (*New Project → Upload Project*).
`main.tex` is the main document and compiles with the default pdfLaTeX compiler. `make_tables.py` and
this README are not needed there.

## Local build

1. Execute the notebook (see the repository README). It writes the figures to `report/figures/` and the
   results to `results/`.
2. From the repository root, regenerate the tables:
   ```bash
   python report/make_tables.py
   ```
3. Compile, e.g. with [Tectonic](https://tectonic-typesetting.github.io) (`brew install tectonic`):
   ```bash
   cd report && tectonic main.tex
   ```
   or with any LaTeX distribution: `latexmk -pdf main.tex`.
